# Verification evidence

This directory contains compact test logs, numerical reports, benchmark receipts
and frozen solver snapshots from development on an Apple M4 Max / Metal.
Reports distinguish bounded engineering checks from scientific qualification;
see [the current status](../docs/STATUS.md) for superseding results and retained
failures. Failed studies remain failed.

Downloaded grain libraries, raw publications, full histories, checkpoints and
per-chunk recovery files remain local and are excluded from Git. Their hashes and
source identities remain in receipts where available. Reproducing a private-shape
study requires acquiring and preparing its documented inputs; a report alone does
not provide those inputs. Synthetic fixtures are generated by
`examples/create_fixtures.py`.

The latest full Metal suite is `verification-mesh-cull-compact-v4.log` (37 passed).
The latest mesh force report is
`hostun-mesh-force-cull-compact-v1/report.json`. The sustained optimization
comparison is `hostun-mesh-performance-comparison-v1.json`. These reports do not
establish dense-soil performance, quadrature convergence or experimental validation.
